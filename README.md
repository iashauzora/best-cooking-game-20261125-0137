**Sizzle Street Kitchen** — an original cooking game for the browser. Orders land on the board; you stack each dish bottom-to-top from the counter bins, send patties, chicken, bacon, eggs and mushrooms to the grill and catch the green PERFECT zone before they burn, then serve from the pass for the price plus a speed tip. Streaks add bonuses, levels raise the rush with more orders, shorter patience and bigger recipes, and three walk-outs end the shift. Fully offline static files (canvas + WebAudio-synthesised sounds, no assets to load), played with mouse or keyboard: keys 1–0 pick ingredients, Q/W/E work the grill, Enter serves, Backspace bins the plate.

## Run it

```sh
# play: serve the static game and open it in a desktop browser
cd game && python3 -m http.server 8080   # then visit http://localhost:8080

# hand in: package the entry the way the grader does
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
